## Two ways to learn

- **Full path**: read every lesson in order, from scratch.
- **Fast-track** (for experienced developers): in each lesson read the *TL;DR*, *Myths vs Facts*, *Senior lens* and
  *Interview corner*, take the tier checkpoint, and go deep only where the checkpoint shows gaps.
